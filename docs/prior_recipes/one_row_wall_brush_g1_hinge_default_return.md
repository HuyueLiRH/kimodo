## Raw Generation Recipe

Use one raw KIMODO/G1-RP motion generated by the web-equivalent native right-hand constraint path.

Prompt:

```text
A person stands still and slides the right palm flat on the outside surface of a wall from left to right.
```

Generation constraints:

| Label | End effector | Frame | Right-hand point | Wall / brush-tip point |
| --- | --- | ---: | --- | --- |
| `row_1_start` | `right-hand` | 36 | `[-0.12, 0.92, 0.28]` | `[-0.12, 0.92, 0.45]` |
| `row_1_mid` | `right-hand` | 51 | `[0.0, 0.92, 0.28]` | `[0.0, 0.92, 0.45]` |
| `row_1_end` | `right-hand` | 66 | `[0.12, 0.92, 0.28]` | `[0.12, 0.92, 0.45]` |

Geometry:

- Coordinates use Y-up world meters.
- `wall_surface_z = 0.45`
- `brush_length_m = 0.17`
- The KIMODO right-hand constraint point is shifted from the wall / brush-tip point toward the robot body along `-Z`.

## Accepted Postprocess Pipeline

Pipeline stages:

1. Start from the best raw/base wall-brush motion.
2. Apply the existing light-lock smooth-return cleanup to preserve the natural wrist/hand orientation better than full arbitrary FK refit.
3. Build a straight line target for the right hand over the brush segment:
   - frame 36: `row_1_start`
   - frame 51: `row_1_mid`
   - frame 66: `row_1_end`
4. Refit only the legal G1 physical right-arm hinge DoFs:
   - Kimodo joints: `[26, 27, 28, 29, 30, 31, 32]`
   - G1 hinge indices: `[22, 23, 24, 25, 26, 27, 28]`
   - Do not optimize helper/end-effector joint `33`.
5. For the return segment, use a body-relative default return:
   - default source: frame-0 physical right-arm hinge angles
   - return frames: 67-101
   - return curve: smootherstep in G1 right-arm hinge angle space
   - semantics: return the right arm to the robot's default/debug posture relative to the current body/root, not to the absolute world-space frame-0 hand point
6. Disable final edit-mask taper for this return pass.

The final taper is disabled because the return target includes frame 101. Tapering the end of the edit window weakens the final frame and lets it drift back toward the previous bad final pose.

## Review Notes

The user accepted this pipeline because it keeps the useful wall-brush behavior, keeps the right hand close to a straight stroke through the three declared points, avoids the impossible upper-arm freedom seen in arbitrary SO(3) refits, and returns the right arm to the stable default/debug posture at the end.

The 27-position batch suggests the treatment generalizes well for most positions. The main remaining review task is visual inspection of right-shifted wide strokes, especially `x0p08_w0p30`, where the G1 hinge-constrained right arm appears closest to the reach/naturalness boundary. If the return appears visually too fast on some positions, the output duration may be standardized to a longer fixed length, such as 120 frames, while keeping all generated priors at the same final frame count.
